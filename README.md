# Valdir Pereira — Portfolio

Site pessoal one-page em Next.js (export estático), publicado em [valdirnp.dev](https://valdirnp.dev).

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build estático (Netlify)

```bash
npm run build
```

A pasta `out/` é o artefato publicado. Configuração em `netlify.toml`.

## Conteúdo

Dados editáveis em `src/data/` (`profile`, `experience`, `skills`, `projects`, `education`).
